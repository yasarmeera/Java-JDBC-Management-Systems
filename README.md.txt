# Java JDBC Management Systems

A collection of Java-based management systems developed using
Core Java, JDBC, and MySQL.

## Projects

### 1. Student Management System

A JDBC-based application for managing student information.

#### Modules

- Student Registration
- Student CRUD Operations
- Course Management
- Course Enrollment
- Attendance Management
- Marks Entry
- Result Generation

#### Tables

- students
- courses
- enrollments
- attendance
- marks

#### JDBC Concepts

- CRUD Operations
- PreparedStatement
- Foreign Keys
- JOIN
- Transactions
- Commit / Rollback
- Exception Handling

---
