# Java JDBC Management Systems

A collection of Java-based management systems developed using
Core Java, JDBC, and MySQL.

## Projects

### 1. Student Management System

A JDBC-based application for managing student information.

#### Modules

- Student Registration
- Student CRUD Operations
- Course Management
- Course Enrollment
- Attendance Management
- Marks Entry
- Result Generation

#### Technologies

- Java
- JDBC
- MySQL
- Eclipse

---

### 2. Employee Leave Management System

A JDBC-based application for managing employees and their leave requests.

#### Modules

- Employee Registration
- Employee Search
- Apply Leave
- View Leave Requests
- Approve / Reject Leave
- Leave Balance Tracking

#### JDBC Concepts

- CRUD Operations
- PreparedStatement
- Foreign Keys
- Transactions
- Commit / Rollback
- Exception Handling

#### Technologies

- Java
- JDBC
- MySQL
- Eclipse
